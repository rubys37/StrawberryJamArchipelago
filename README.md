# Strawberry Jam Archipelago

an archipelago implementation for strawberry jam!

anyone that wants to playtest this initial version and suggest changes/improvements!!!! download this zip file and put it directly into your mods folder (no unzipping the zip :3)
your mods folder is in your steam install. by default, it is located at "C:\Program Files (x86)\Steam\steamapps\common\Celeste\Mods"
then enable it using everest, turn on strawberry jam, and get playing!
